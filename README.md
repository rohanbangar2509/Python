## 📚 Learning Roadmap

### Tier A — Core Python

- Variables, operators, and conditionals
- Loops and control flow
- Functions and reusable code
- Strings and text processing
- Lists, tuples, sets, and dictionaries
- Comprehensions and basic problem-solving

### Tier B — Python for Data Engineering

- File handling with `pathlib`
- Reading and writing CSV and JSON
- Data cleaning, validation, and deduplication
- Exception handling and logging
- Datetime and time-zone handling
- Iterators, generators, and memory-efficient processing
- API requests, pagination, retries, and error handling

### Tier C — Interview Concepts

- Mutable vs. immutable objects
- List vs. tuple vs. set vs. dictionary

- Connecting Python to PostgreSQL
- Parameterized queries and safe database operations

### Tier E — Practical Data Engineering Scenarios

- CSV validation and transformation

- ETL pipeline components
- Logging, error handling, and processing metadata

*The roadmap represents planned learning areas, not a claim that every topic or project has already been completed.*

## 🧠 My Practice Approach

For each problem, I aim to:

1. Understand the problem and identify the expected input and output.
2. Develop a clear solution before optimizing it.
3. Handle invalid inputs, missing values, and edge cases.
4. Explain the approach and analyse time and space complexity where relevant.
5. Run test cases and improve code readability.
6. Consider how the solution could be used in a real data-processing workflow.

## ▶️ Run a Solution

Make sure Python is installed, then run an individual practice file from the repository root:

```bash
python "Tier A/Variables, Operators & Conditionals/Q_01.py"
```

On systems where the Python 3 command is required, use:

```bash
python3 "Tier A/Variables, Operators & Conditionals/Q_01.py"
```

Replace `Q_01.py` with the question file you want to execute.
